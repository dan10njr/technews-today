# TechNews Today

Bem-vindo ao **TechNews Today**! 🚀  
Este é um portal de notícias moderno sobre o mundo da tecnologia, desenvolvido com **HTML5 semântico** e um visual **Dark Mode em CSS3**.

---

## Destaques do Projeto

-  **Esqueleto 100% Semântico:** Estruturado com `header`, `main`, `article`, `section` e `footer`[cite: 1].
-  **"Leia Mais" sem JavaScript:** Utilizando as tags nativas `<details>` e `<summary>`[cite: 1].
-  **Mídia Integrada:** Vídeo do YouTube embutido com `iframe`[cite: 1].
-  **Newsletter Interativa:** Formulário completo com campos de entrada, seleção, checkbox e validação nativa[cite: 1].
-  **Visual Escuro & Moderno:** Estilização desenvolvida em CSS3 com gradientes, sombras e cores vibrantes.

---

## Tecnologias Utilizadas

- **HTML5**
- **CSS3**
